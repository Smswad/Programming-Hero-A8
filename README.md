# HERO.IO - Programming Hero A8

## Description

**HERO.IO** is a modern, responsive web application designed to showcase innovative apps that make everyday life simpler, smarter, and more exciting. The platform features a curated list of trending apps, installation tracking, and detailed app insights including downloads, ratings, and reviews.

Built with a focus on user experience, the application offers a seamless interface across mobile, tablet, and desktop devices, featuring dynamic animations and a premium design aesthetic.

## Technologies Used

This project is built using the following technologies:

### Core
- **[Vite](https://vitejs.dev/)**: Next Generation Frontend Tooling
- **[React](https://react.dev/)**: The library for web and native user interfaces
- **[React Router](https://reactrouter.com/)**: Declarative routing for React web applications

### Styling & UI
- **[Tailwind CSS](https://tailwindcss.com/)**: A utility-first CSS framework
- **[DaisyUI](https://daisyui.com/)**: The most popular component library for Tailwind CSS
- **[Lucide React](https://lucide.dev/)** & **[React Icons](https://react-icons.github.io/react-icons/)**: Icon libraries for modern apps

### Libraries & Utilities
- **[Recharts](https://recharts.org/)**: Redefined chart library built with React and D3
- **[Axios](https://axios-http.com/)**: Promise based HTTP client for the browser and node.js

## Features
- **Responsive Design**: Fully optimized for Mobile, Tablet, and Desktop.
- **Dynamic Content**: Real-time searching and sorting of applications.
- **Interactive UI**: Smooth animations, hover effects, and engaging layout.
- **Installation Tracking**: Simulate app installation and management.
- **Data Visualization**: Visual charts for app ratings and statistics.

## Getting Started

1.  **Clone the repository**
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run the development server**:
    ```bash
    npm run dev
    ```
4.  **Build for production**:
    ```bash
    npm run build
    ```
